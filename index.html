添加流程卡片

一张卡片表示“谁负责 + 客户/对象当前处于什么状态”。从卡片右侧圆点拖到目标卡片，即可添加流转规则。

添加业务内容

客户触达内容：对客户说什么、用什么权益、看什么业务指标。执行跟进动作：谁执行、执行什么、看什么过程指标。

画布操作

拖拽卡片调整布局；空白处拖拽平移；Shift + 空白拖拽框选；Ctrl/⌘ + 点击多选；Ctrl/⌘ + C/V 复制粘贴。双击流程卡片或流转规则标签可打开右侧编辑。

提交规则
1. JSON 是正式输入；Mermaid 仅用于业务沟通。
2. errors 清零后才允许 ready_to_submit。
3. 缺失业务字段必须保留“待确认”，不得填 0 或编造。
4. “无行为要求”和“未发生行为”必须区分。
5. 源 / 目标执行人不同且未标记 handoff 会阻断。
6. 本 MVP 不写工单、不写 registry、不直接生成提交表。
